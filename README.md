# 🌱 Sistem Informasi PROKLIM Kalimantan Barat

**Sistem Informasi Terpadu Program Kampung Iklim (PROKLIM) Kalimantan Barat** merupakan platform digital yang dikembangkan untuk mendukung pengelolaan dan penyajian data serta informasi terkait lingkungan hidup dan aksi perubahan iklim di Provinsi Kalimantan Barat.

Sistem ini mencakup pengelolaan dan publikasi berbagai informasi, seperti **Program Kampung Iklim (PROKLIM), Inventarisasi Gas Rumah Kaca (IGRK), pengelolaan sampah, kualitas lingkungan, Limbah B3, edukasi lingkungan, regulasi, berita, galeri, dan laporan**.

## 🛠️ Teknologi

* **Framework:** Laravel 12
* **Programming Language:** PHP 8.4
* **Database:** MySQL
